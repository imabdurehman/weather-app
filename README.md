# WeatherNow – React Weather Forecast App

A modern and responsive Weather Forecast application built with React. Users can search for any city and view real-time weather information using WeatherAPI. The application features API integration, global state management with Context API, and Local Storage persistence for search history.

---

## Features

- Responsive design for desktop and mobile
- Real-time weather search by city
- Display weather information including:
  - City Name
  - Temperature
  - Weather Condition
  - Humidity
  - Wind Speed
  - Weather Icon
- Loading state while fetching weather data
- Error handling for invalid city names
- No Data state on initial load
- Last searched city
- Recent searches history
- Global state management using Context API
- Search history persistence using Local Storage
- Modern Glassmorphism UI
- Clean and reusable component architecture
